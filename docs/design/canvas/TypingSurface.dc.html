CORRECT
#E8EDF2 · weight 500. Full contrast, no decoration.
CURRENT
A 3px caret that moves smoothly between characters. Never a background block.
WRONG
Colour and a 3px underline, so it never signals by hue alone. The character you typed stays visible — never replaced.
PENDING
Dimmed but fully laid out. Space is reserved before typing starts.
Zero layout shift, ever. The full line renders at final metrics before the first keystroke — only colour and the caret change as you type. Monospace at 28px makes every character advance identical, so a wrong character can never reflow the line beneath it.
